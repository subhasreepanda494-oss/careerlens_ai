# CareerLens AI — Interactive Workspace Scope

## Active Experience

CareerLens now provides an interactive job-readiness workspace with the following modules: landing and guided entry, local resume-file validation, illustrated resume analysis, illustrative job-role comparison, local skill-roadmap progress, job-specific interview-answer practice, and a browser-session application tracker.

## Evidence Labels

Every workspace section uses one of four clear labels. **User-provided** identifies information chosen or entered by the visitor. **Resume-extracted** identifies the structure of information that a future parsing service would derive from an uploaded resume. **Source-based** identifies the intended category for connected job-source data. **AI-generated** identifies recommendation and feedback content. The active demo also uses a **Demo preview** label for illustrative values.

## Current Simulation Boundary

The workspace is intentionally client-side and does not upload a resume, create an account, retrieve vacancies, submit applications, or call an AI model. The example resume insights, job briefs, match scores, learning priorities, and feedback are clearly labelled illustrative material. They are neither verified job listings nor hiring predictions.

## Future Connection Points

A production implementation can later connect the existing resume-upload flow to secure file storage and parsing; replace illustrative role briefs with permitted job data; persist user-controlled application tracking; and replace the interview feedback demonstration with a suitably disclosed AI endpoint. Those integrations are outside this current frontend deliverable.
