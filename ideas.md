# Chosen Direction — Evidence Ledger

## Design Movement

**Editorial functionalism with data-journalism clarity.** CareerLens AI will feel like a personal briefing desk: structured evidence, carefully chosen emphasis, and AI outputs presented as helpful annotations rather than opaque authority.

## Core Principles

1. **Truth is visible:** extracted resume facts, externally sourced job information, and AI-generated recommendations will always have visibly different labels and visual treatment.
2. **Momentum is practical:** every dashboard module should point to a concrete next action, not merely report a score.
3. **Hierarchy earns attention:** bold display type, quietly structured body copy, and deliberate whitespace will make the most important decision clear at a glance.
4. **Data remains human:** charts will clarify progress and gaps, but no data object should appear without a plain-language interpretation.

## Color Philosophy

The core environment is a **cool paper-white / mist-blue workspace**, selected to communicate clarity and trust rather than algorithmic mystique. **Lens Blue (#2563EB)** is the decisive interaction color: it marks verified insight, navigational direction, and primary actions. **Indigo Ink (#312E81)** supplies depth for editorial hierarchy. A restrained **Aubergine Violet (#7C3AED)** identifies AI-generated recommendations, creating an explicit visual distinction between source-backed data and model-led guidance. Warm amber is reserved for warnings and priorities; green is reserved for completed preparation actions. The result is a blue–indigo–violet system that looks professional rather than gradient-led.

## Layout Paradigm

The app uses a **navigation rail + variable editorial canvas** rather than a rigid centered grid. Primary dashboard views start with an asymmetric “career brief” header, then branch into staggered evidence panels: a prominent score or decision panel on one side and short stacked next-action modules on the other. Sections use soft canvas bands, shelf-like dividers, and scoped cards that change density depending on the task (analysis, planning, interview practice). The landing page uses a split composition with the value statement occupying an editorial left column and an abstract resume-to-roadmap visual field on the right.

## Signature Elements

1. **Lens marks:** small concentric circle motifs appear in score gauges, navigation indicators, and the logo to reinforce the “CareerLens” idea.
2. **Evidence chips:** compact labels such as “Extracted from your resume,” “Source-backed,” and “AI recommendation” identify the provenance of every meaningful data point.
3. **Editorial rules:** indigo hairlines and numbered step markers divide information into readable career moments instead of anonymous dashboard blocks.

## Interaction Philosophy

Interaction should feel like reviewing a carefully assembled personal dossier. Hover states lightly lift actionable panels, filter changes update visibly without disorienting the page, and guided CTAs state the next human outcome (“Review skill gaps”, “Set interview date”) rather than technical functions. Async activity is transparent: every loading, upload, analysis, and generated result gets a visible state and a clear recovery action.

## Animation

All motion is restrained, purposeful, and typically 160–280ms using a confident ease-out curve. Dashboard cards enter in short staggered sequences only on initial page load; score arcs animate once into their measured value; chips and controls transition by opacity and subtle translation. Upload and processing surfaces use rhythmic progress movement, never an indefinite decorative spinner without context. Reduced-motion preferences will disable all nonessential entrance animation.

## Typography System

**DM Serif Display** supplies the human, editorial display moments: landing headlines, page titles, and key score figures. **Manrope** is the technical UI face for navigation, labels, controls, tables, and body copy. The hierarchy favors expressive, left-aligned headlines; precise medium-weight labels; generous line spacing for explanatory content; and compact monospaced-style numerals only where comparison matters. Generic Inter is intentionally excluded.

## Brand Essence

**Positioning:** CareerLens AI turns a candidate’s documented experience into a transparent, action-oriented path from resume review to interview readiness.  
**Personality:** analytical, reassuring, candid.

## Brand Voice

Headlines are direct, optimistic, and evidence-led; CTAs name the next decision; microcopy explains uncertainty instead of hiding it. Avoid empty promises and generic startup language.

> “See what your resume proves—and what your next role requires.”

> “Turn one missing skill into this week’s preparation plan.”

## Wordmark & Logo

The mark combines a rounded **career path / upward step** with a circular **lens ring**, creating a forward-pointing aperture. It is paired with a bespoke wordmark where the “C” subtly echoes the lens circumference. The product name is never represented as unmodified default text in prominent branding.

## Signature Brand Color

**Lens Blue — #2563EB.**

## Style Decisions

1. **Evidence-led page rule:** Every principal application page must include an editorial evidence structure—such as a numbered ledger band, source trail, or provenance divider—before its operational controls or result cards.
2. **Lens-path motif rule:** The lens/path mark must recur beyond the logo through score gauges, navigation cues, section markers, and quiet visual overlays.
3. **Illustration rule:** Prominent visuals should portray resume evidence becoming an annotated career path through lens rings, ledger marks, and sourced signals; generic floating dashboard imagery is not sufficient by itself.
4. **Action-language rule:** Calls to action must name the user’s decision or outcome, rather than a generic feature label.
